Biogas rate & yield estimator

Estimates cumulative biogas volume and production rate from a first-order digestion-kinetics model. The model is solved on the server (Euler and 4th-order Runge–Kutta) and checked against its closed-form analytical solution. Enter the digestion parameters and run the model to see the results and the numerical accuracy plot.

Input parameters

Maximum cumulative volume the digester will yield as time → ∞.

Governs how quickly production approaches V∞: dV/dt = k(V∞−V).
